`BrushAnalysisRequest` is a separate type wrapping an owned, one-use original-source brush admission. It cannot be passed to existing display/GPU/export consumers. Its private render mode captures linear sRGB/D65 RGBA32FPx4 at the working boundary. Display factories keep their original mode and estimate. Working admission adds eight bytes per output/expanded pixel to the conservative whole-frame or stripe estimate, retaining the original32Mi source-pixel/3GiB limits and lease accounting. Outputs and their explicit shared read-only images keep the split reservation after the request is destroyed. Original intent, geometry, immutable source copying, cancellation and one-use checks remain.

`ScopesEngine::analyzeLinear` accepts complete finite unassociated linear-sRGB FP32 images and directly counts1024 bins without an intermediate integer conversion. Counts clamp only for graph indexing; linear range counters mean all RGB<=0 and any RGB>=1. They do not use the unchanged encoded-display near-black/near-white thresholds or claim sensor clipping. Alpha is validated and does not weight channels, matching existing histogram ownership. Partial accumulators are bounded by the existing worker budget; nonfinite pixels/cancellation discard the whole result. `analyzeWorking` collects a complete admitted stripe visit before returning counts.
