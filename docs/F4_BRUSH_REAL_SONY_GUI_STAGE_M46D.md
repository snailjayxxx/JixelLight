## Real-source user workflow

`--sony-brush-canvas-smoke-report` requires exactly one checksum-pinned public Sony A7 IV07 ARW:69,120,000 bytes, SHA-256 `aa12ae9ef42a8254afc11daddb706dee7d2f0cd7b869f44f377c4470fd7fdc4d`. Ordinary LibRaw import must produce7028×4688 native RGBA64,32,947,264 pixels. There is no synthetic fallback, injected source image or pre-admission reduction. Timing begins before fingerprint/import and retains a60,000ms internal limit; the80-second wrapper is only process cleanup protection and cannot accept a slower report.

The scenario clicks the actual Paint tool and exposure slider, sends pointer moves and Escape, verifies that a cancelled transient stroke creates no committed intent/history, then releases a stroke as one Undo. A displayed midtone must change by at least3/255. Actual Undo/Redo buttons must restore the baseline/painted pixel within2 codes. A project is saved/flushed/reopened through public controller operations, with brush and unrelated adjustment intent preserved; the reopened selected layer accepts another transient stroke/Escape without committing it. Project file-picker automation is not claimed.

The actual scope ComboBox and Full resolution checkbox select an exact waveform. Both histogram and plot must count all32,947,264 native source pixels, the current Qt Quick plot image must be loaded, and at least64 sampled mint waveform pixels must be visible in the actual window. Final pointer input must be enabled with the current controller hint. Source bytes are checked again; budget evidence must show the unchanged shared3GiB limit and a positive reservation peak within it. Native GPU presentation is required for the GPU mode, while the brush producer is accurately recorded as CPU reference.

## Capture correctness and preference isolation

The M4.6C macOS CI screenshot contains the painted stroke, but its1180×720 native backing store was smaller than the requested1180×800 window. The former size-ratio mapping read above the stroke. Photo samples, scope-ink samples and controls crops now use the renderer device scale, refuse off-capture points and clip regions without stretching. A new120-second `brush-capture` shard covers this exact clipped-window failure, DPR2, fractional DPR1.25 and bounds. This brings CTest to43 without changing existing gates. The implementation follows Qt6.8's [native software grab](https://github.com/qt/qtdeclarative/blob/v6.8.3/src/quick/scenegraph/adaptations/software/qsgsoftwarerenderloop.cpp) and [QQuickWindow capture contract](https://doc.qt.io/qt-6.8/qquickwindow.html#grabWindow).

QA also exposed a separate settings-isolation defect: temporary HOME/APPDATA alone did not isolate native macOS preferences. All six desktop smoke modes now use a process-owned temporary QSettings INI store before controller/QML construction, plus QStandardPaths test mode. Ordinary application startup keeps its normal native preferences. An existing affected preference store was backed up privately before this fix; unknown earlier preference values are not guessed or silently restored. User-specific values and notification details remain outside the repository.

Full native photographs and project files stay in a separate private temporary directory outside the public report directory. Public evidence contains numerical probes, source/capture hashes, logs and only the cropped Develop controls/waveform panel. The wrapper rejects private captures beneath the public report directory. The pinned review photograph is never copied into validation artifacts or deployment packages.
