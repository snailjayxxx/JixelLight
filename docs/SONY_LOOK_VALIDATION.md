# alpha.8 Sony 功能验证记录

本文件记录本地已完成验证，不把 CI 待运行、人工预设或合成相机字段说成已完成实机 Sony 标定。最新原生平台结果以本分支对应 PR 的工作流及下载包 manifest 为准。

## 本地环境与结果（2026-09-07）

Release，Qt 6.8.3，Exiv2 0.27.6，Linux；GPU 使用 Mesa llvmpipe 软件 OpenGL 计算后端。原有 core-tests、performance-correctness、raw-worker-stack 和新增 sony-look 均通过。GPU suite 17 项通过、0 失败、0 跳过，新增外观/LUT案例最大差值 2/65535；保留的历史密集用例最高 9/65535。阈值仍为最大 40/65535、相应平均误差检查及 GPU 实际像素的精确直方图检查。

新增 sony-look 16 个 QtTest 通过项（含 init/cleanup），覆盖：
- Sony1/Sony2 数字标签、八项参数、缺失/非法/冲突/未知值、旧款共享名字的保守识别。
- 在 JPEG 文件内实际写入/解析合成 Sony MakerNote；这是容器解析测试，不是相机直出。
- 按拍摄设置逐照片解析、JPEG 不自动重复套用、旧项目 look 缺省关闭。
- look JSON 和 2/17/33³ LUT 往返/恒等/篡改校验、cube 输入边界拒绝。
- 十二种预设、强度零、关闭、黑白、八项细节/色彩参数。
- 空间细节 128 行分块/任意 ROI 与整图像素完全一致；全分辨率统计与整图统计一致。
- 参考文件配对检查、手选状态、独立 provider/直方图、不覆盖原图或参考文件。
- 空间留出拟合、错误方向/比例/过小图像/取消拒绝。
- 真实 Leica M8 DNG 开发链，加人工颜色变换 JPEG 参考完成后台拟合，保持曝光调整；更改参数时旧拟合取消。

GPU 外观测试：12 个近似预设、每个预设启用八项微调和邻域细节、2/17/33³ LUT、四种输出色彩空间、方向和源图上传复用。CPU/GPU 都作用相同 LUT，不用 CPU 返回图假冒 GPU 通过。

真实 DNG GUI smoke 已显示外观/参考并排、参考直方图和当前图全分辨率统计。布局检查发现宽度分配问题并修正，后续 smoke 要求参考像素摘要与 look.active 同时存在。部署包测试同样要求 FL 外观与独立参考，移除开发 Qt 搜索路径再分别启动 GPU 和 CPU 路径。

## 明确没有证明的事项

没有用户提供的真实 Sony ARW + 同次拍摄原始 JPEG，没有机型/镜头/照明/曝光/全部十二种风格组合的标定数据。以上测试证明解析规则、应用链、参考拟合算法与导出的一致性，不证明内置预设与 Sony 色彩相同，不证明所有机型都会写出所有标签。单照片 LUT 不等同于通用相机 profile。

云端/软件 GPU 验证不替代用户实体 Apple/NVIDIA/AMD/Intel 显卡测试。版本仍为 unsigned alpha；不包含签名、公证或稳定发行认证。main 与原 alpha.7 分支不自动替换。
