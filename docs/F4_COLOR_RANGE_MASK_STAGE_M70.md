# F4 — Independent color range exposure mask

One independent color mask applies -3..3 EV using a stored Oklab center and the existing Point Color circular hue/chroma/lightness weights, including neutral confidence and smooth shoulders. Inversion selects the complement. Selection reads post-spatial input before user WB/exposure and all local gains. Color and luminance masks use the same immutable input, then apply their gains before the existing gradients/brush/vignette. Unselected, disabled and zero-EV pixels bypass exactly; alpha is unchanged. No additional plane, neighborhood or source clipping is introduced.

The optional strict schema1 `colorMask` snapshot has nine fields: schema, space, enabled, inverted, exposure, center and three ranges. Factory defaults remain absent; custom disabled intent survives. Six commands cover toggles, encoded-sRGB/manual Oklab selection, parameter updates and isolated reset. Masks-only transfer, presets, XMP, copies, durable projects/history and CLI retain independent state. The plan appends two vec4 slots to the unchanged63-slot prefix (65 slots/1040 bytes); shared shader declarations follow the size. Engine/profile identity and source files are unchanged.

The bilingual persistent panel provides color dialog, working canvas picker, inversion, four controls and reset. A shared source-sampling helper preserves the original Point Color boundary and adds an input-mask boundary. Immutable requests capture target, source, plan, point, photo epoch, prepare generation and revision. Changing photos/edits or requesting another picker rejects old work. A valid manual color selection cancels pending sampling even when it confirms an unchanged color; invalid selections remain atomic. Source selection is independent of output/monitor ICC.

This stage is an explicit CPU reference. GPU presentation uploads the complete result and records `color-range-mask-cpu-stage`; native brush compute admission refuses the stage. Spatial CPU caches remain reusable as color-mask controls change. All existing numerical, source32Mi-pixel, shared3GiB and45/60/120-second gates remain.
