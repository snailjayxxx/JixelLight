## User behavior

Choose **Paint brush** on the canvas. The right panel expands and scrolls to the brush controls. Select a saved layer or **New layer**, set local exposure, radius, hardness and opacity, then drag on the image. A bounded guide and the actual short-edge brush cursor follow the pointer. The color result applies on release; this is CPU-reference processing displayed through the existing CPU or GPU presentation path. Each completed stroke creates one Undo entry. Escape abandons the current stroke without changing adjustments or history.

The selected layer retains its stable ID, strokes, enabled state and exposure. Its exposure slider groups one drag into one Undo entry; layers can be disabled, removed or cleared. A new stable-ID layer is created only after its first valid completed stroke, so selecting **New layer** does not create an empty document. Disabled layers require explicit enabling before painting. Project save/reopen, history and the existing four export formats consume the same canonical active intent as [M4.6A](F4_BRUSH_PERSISTENCE_STAGE_M46A.md).

The first version uses mouse pressure1 and applies exposure only. Erasing, pressure-device support, continuous color feedback during a drag, richer mask controls and further production acceptance remain future slices. No native GPU brush or native FP32 RAW decoder is introduced.

## Atomicity, identity and resource limits

`beginBrushStroke` captures the exact photo storage key, photo epoch, preparation generation, requested revision, source cache key and complete geometry. Its transient bounded `StrokeBuilder` is outside saved adjustment/history state. `appendBrushStroke` maps the pointer into the complete post-geometry frame, including the current preview ROI; radius uses the complete frame's short edge. Changing the photo/version, crop, viewport/preparation, adjustments or tool cancels the gesture. Invalid coordinates/pressure, overlong paths or stale identities abandon the entire gesture.

`endBrushStroke` checks the captured identity again after emitting the drawing-state signal, including reentrant source changes. It stages a complete candidate, validates the canonical document and preflights whole-operation work before publishing. Only then does one history action install the result. Failed work/validation leaves the previous document and history intact; a subsequent legal gesture remains possible. No pixel snapshot or GUI-thread pixel rendering is introduced by the preflight. Pixel work still needs a separately reserved owning one-use request.

Unchanged limits: admitted source32Mi pixels/aggregate3GiB; old research API2Mi pixels; tile work8Mi/operation work96Mi including repeated halos. Document limits remain16 layers,64 strokes per layer,4096 dabs per stroke and16,384 total dabs. Style ranges remain radius[.002,.5], hardness/opacity/pressure[0,1], exposure[-3,3]EV. Resampling and guides are bounded; the guide retains at most1024 points independently of saved dabs. GPU40/65535, original RAW GUI60,000ms and performance/large/new CTest shards120s remain unchanged.
