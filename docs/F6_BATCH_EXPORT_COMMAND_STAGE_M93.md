# Batch export command routing — M93

`export.batch` accepts a native `folder` and optional `photos`, `space`, `quality`, `format`, `pattern` and `sequenceStart`. Omitted photos means the entire catalog; an explicit array must contain1–1000 unique exact existing version keys. Empty, stale or duplicate identities reject the entire request and never widen to all. All-catalog export retains its existing catalog-size support. The schema labels this desktop command; offline sessions retain repeated `export.run` snapshots and reject a late `export.batch` before any outputs.

The public dispatcher and existing `exportVersions`/`exportAll` adapters share pure parameter decoding and one execution helper. Legacy adapters retain URL handling, format aliases, color normalization, clamped quality and ignored sequence values when the template is empty. Existing catalog-order name planning, date requirements, NFC/case-folded occupied-name checks, protected-original checks, new-file staging and queue cancellation remain. The accepted request freezes source paths, names, states and identities before the user can edit or change selection; true means accepted, with `exportFinished` reporting completion. Selected exports retain their trace event, with canonical command fields. Whole-catalog events avoid retaining an unbounded list of version keys.

New Core cases cover whole-catalog membership/state snapshots, independent PNG16/Display-P3 pixel and ICC references, whole-plan refusal, malformed/empty/stale identities and an asserted foreign-thread call. Existing selected-version freeze coverage now uses the public command. The real missing-source App probe uses the public selected batch command after reviewed relink and checks its canonical trace; its existing package context and20-second internal deadline remain. The ordinary/deployed CLI safety checks inspect the desktop scope and reject late batch commands without earlier session outputs.

This is a private implementation, not compiled or qualified yet. Required validation includes Core232/session12/recipe9, CLI80, real Cocoa relink, normal-App CPU/Metal DPR1/2, full102/all96 groups, the existing24 native workflows and source/binary invariance. No image/RAW/GPU precision, engine, resource or deadline policy is changed. Remaining F6 action routing and complete platform/package qualification are not declared complete.
