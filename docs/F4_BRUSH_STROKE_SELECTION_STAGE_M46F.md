The brush editor previously allowed removal of the last stroke or the entire layer. Selecting an earlier stroke now displays its stored centerline in yellow. **Delete stroke** removes that whole stroke as one Undo step, preserving subsequent strokes, other layers and unrelated adjustments. Removing the only stroke prunes that exact layer; Undo restores it. Disabled layers remain editable without enabling their effect. Selection lives only in the current UI session.

## Identity and resource boundaries

The shared GUI/CLI command is `{"command":"mask.brush.remove-stroke","layer":"existing-id","index":0}`. Indexes are zero based, finite integers within the selected layer. Unknown identities, fields, wrong types, fractional/negative/missing indexes and malformed documents fail before mutation; command arrays retain atomic rollback. Existing schema1 remains unchanged.

The controller's read-only selection query returns at most1,024 normalized center points, preserving the stored first/last points. It does no image processing or source copying. The transient SHA256 token binds catalog epoch, photo storage identity, source epoch/cache identity, geometry, index and the entire canonical selected layer. A changed layer or reused index cannot silently remove another stroke, including when stored strokes are identical. The remove API checks that token before touching mutable state/history. The overlay reprojects the guide into the current viewport; photo/layer/adjustment/tool changes clear UI selection.

The guide shows the path of the whole stroke, rather than mask coverage.
