# F4: bounded asynchronous pressure-QA evidence capture

[CI325](https://github.com/snailjayxxx/JixelLight/actions/runs/41037078307) passed its complete three-platform and deployed-package audit for the preceding brush change. The slowest Windows deployed-package transparent CPU pressure run took 44,940 ms against the unchanged 45,000 ms limit, leaving only 60 ms. The preceding CI322 and CI323 Windows failures and their original evidence remain preserved.

The owned-image pressure QA still captures every UI frame synchronously. A single bounded worker writes and hashes the resulting lossless PNG85 files while later UI checks run; at most two frames wait in the queue. The test waits for all writes and hashes before it can pass, and that wait remains inside the 45-second measurement. All 22 original screenshots, pressure and color checks, plan verification and exact PNG16/ICC export remain required. A failed write is a test failure, and the test attempts to preserve a diagnostic screenshot.

The queue is used for QA evidence capture; it does not change the product's brush rendering or RAW decoder. In an isolated controlled UI experiment, 22 frames saved asynchronously were byte-identical to PNGs saved synchronously from the same captured frames. An isolated single-run offscreen comparison took 5,671 ms before and 5,338 ms after; this is not a Windows measurement or a performance guarantee. Queue behavior tests cover ordered output, detached image snapshots, bounded pending frames and failed writes. A test-only injected worker exception also failed safely. The first private build used an SDK without AGL and failed; that failure and the successful build with the configured SDK were retained.
