# F4: explicitly choose stabilization for tiny pen movements

The brush panel adds an explicit pen-input choice, originally **Stabilize tiny pen movements** / **稳定笔尖微移**. The compact M48M repair places **Steady pen ½px** / **稳笔 ½像素** in the existing Layer/Mode row and retains the full explanation in its tooltip. It starts unchecked and applies only to new stylus gestures after the user selects it. Movement within half an image pixel of the gesture's current anchor holds the previous position; larger movement establishes the next anchor. Every pressure packet passes through unchanged. The choice remains an editor-session setting and is disabled while a gesture is held or a recovery decision is pending.

This is an explicit input rule. It changes the position the user supplied. A retained 512×320 hard-edge counterexample changes one pixel's coverage from 0.5 to 0 after a 0.49-image-pixel movement, so the positional bound is not a color-error guarantee. Complete unfiltered unique-position pressure jitter remains unresolved. Mouse input, the three existing raw controller start routes, old strokes, the sampler, rendering and document formats retain their existing behavior. There is no automatic splitting or partial application and no increase to the 4,096-dab stroke limit, 16,384-dab document limit, work, tile, pixel or shared-memory budgets.

The controller has a separate explicit start route and owns a fresh positional anchor for each selected gesture. Pressure is passed to the existing sampler after only the coordinate rule. Pending recovery remains protected against replacement gestures and the original refusal/explicit-prefix behavior is retained when the checkbox is off or a longer selected path still exhausts the original limits.
