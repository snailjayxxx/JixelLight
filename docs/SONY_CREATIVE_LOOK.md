# Sony 创意外观 — alpha.8

本功能由三个独立层组成：读取**拍摄记录**、显示**相机/参考预览**、应用**当前编辑外观**。它们不是同一份像素，也不是同一项状态。软件不使用 AI 识别或联网发送照片。

## 使用方法

导入 ARW 后，右侧“索尼外观 · 拍摄记录”显示基础外观和相机保存的八项微调。未记录的字段显示“未记录”，不补成零。MakerNote 矛盾、旧 Creative Style 与 Creative Look 无法区分、未知外观会保留字段并停止自动应用。诊断包记录原始字段、来源、有效值、无效值和警告。

“当前编辑外观”可以选关闭、按拍摄设置或手动/导入。新导入的 RAW 使用按拍摄设置模式，但只有明确识别的 Creative Look 才启用；JPEG/TIFF 不自动重复套用。旧项目 JSON 没有 look 对象时保持关闭，避免悄悄改变原来画面。复制/批量同步“按拍摄设置”在目标 RAW 上重新解析它自己的记录，不把上一张的 FL 错当成所有照片的设置。

启用“并排对照相机/参考图”，软件寻找同目录、同名且元数据一致的 JPEG；无法唯一配对时使用 RAW 内嵌预览。也可以手工选择 JPEG。参考来源、实际预览尺寸、色彩依据和参考像素直方图独立显示。自动元数据匹配不是真实性认证；手工选择也不等于已确认同次拍摄。参考图不参与 RAW 导出，禁止覆盖已导入原图或已选参考文件。

选择手动外观后可以调强度和八项微调，也能继续使用基础曝光、曲线及 HSL；外观层和拍摄原值互不覆盖。BW/SE 不提供外观饱和度微调。关闭外观层会返回同一套基础调整结果。导出 JPEG 从当前编辑链生成，并使用所选输出 ICC；并排参考像素不会替代 RAW。

## 内置外观的精度声明

提供 ST、PT、NT、VV、VV2、FL、FL2、FL3、IN、SH、BW、SE 十二个入口。它们是 JixelLight 根据风格方向独立实现的**未标定近似预设**，不包含 Sony 私有曲线、LUT、相机算法或固件。读取了 FL 并不意味着已经重现官方 FL。锐度、锐度范围、清晰度有独立邻域处理，不是简单把所有参数塞进颜色 LUT；参数名称与相机相同，但系数/算法不是 Sony 官方数值转换。

按拍摄设置会选择对应近似预设，并把已读出的有效八项参数作用于该独立实现。缺失参数不更改对应项。用户修改不会重写原始 MakerNote。没有通用、经过实测标定的 Sony 相机配置；不要用这些预设代替需要精确一致性的官方显影。

## 参考拟合：把同一张照片的相机成片作为目标

1. 导入 RAW，等完整 RAW 加载结束；启用并排参考，优先选择同次拍摄、同构图、未裁剪未旋转的 JPEG。RAW 内嵌预览也可以作为低分辨率参考。
2. 点击“拟合本照片”。后台从独立的中性 RAW 显影生成基准，使用冻结的像素与参数版本创建 17×17×17、display-sRGB 域的颜色 LUT。
3. 界面显示留出验证像素的 RGB RMSE。未通过几何、内容或拟合有效性检查时不应用结果。通过后创建“参考拟合/导入 LUT”外观层，并保留已有基础调整。已有曝光等调整仍会作用，所以不是对照原 JPEG 的逐像素复制；进行最初比较时可先保留中性基础调整。
4. 可调外观强度、继续编辑、关闭，或保存为 `.jlook.json`。切图、改参数、改参考会取消/丢弃过期拟合结果，不把旧照片的结果套到新照片。

这是**单照片颜色匹配**，不是多场景相机标定。拟合使用空间分块的训练/验证拆分、颜色覆盖率、梯度相关性和误差门槛；无法可靠对齐或内容差异明显时拒绝。输入相同尺寸/相关性通过不能保证绝对同次拍摄。自动图像配准、畸变矫正匹配、局部遮罩、逐像素风格迁移不在本版范围。

LUT 不学习锐化、降噪、纹理、光学畸变或局部清晰度算法。缺失颜色靠规则化和恒等先验，不保证在其他照片上成立。保存的 profile 带参考来源、模型、像素 SHA256、覆盖率及误差证据；换照片使用仍是未经验证的迁移。参考 JPEG 的量化、压缩、色域裁切或未知 ICC 都会限制精度。

**颜色域限制：**参考/导入 LUT 在 display-sRGB 域处理。使用它时，即使选择 Adobe RGB/ProPhoto 导出，也不能恢复 LUT 之前被压入 sRGB 的颜色。内置参数型近似外观与关闭外观时保留原来的目标宽色域分支。原始 RAW 数据不改写。

## 配置导入/保存

`.jlook.json`：包含版本、独立外观设置、可选 LUT、数值校验和及证据。按拍摄设置保存时固化为本照片的实际外观；重新导入不依赖某个文件名或旁边的 JPEG。

`.cube`：支持 2–33 边长的三维 RGB LUT，红色索引最快；只接受 DOMAIN_MIN 0 0 0 / DOMAIN_MAX 1 1 1、有限且 0–1 的数值。未声明域按标准归一化域解析。仅用于 display-sRGB-to-display-sRGB LUT。普通 cube 没有足够的输入色彩空间说明，软件不能自动鉴别用户把 Log LUT 错当 sRGB；导入前需核实。拒绝 1D/shaper、Log/HDR 扩展域、超范围值、数量不符、未知关键字、超 4 MiB 文件和校验失败的 JSON。不会静默截断后冒充有效。

## MakerNote 字段与识别规则

| 信息 | Sony1/Sony2 标签 | 校验范围 |
|---|---|---|
| CreativeStyle/基础名称 | 0xB020 ASCII | 已知名称/别名；保留未知值 |
| ColorMode/交叉检查 | 0xB029 | 已知枚举；不把未知名称强制改成 ST |
| 对比度 | 0x2004 | -9…9 |
| 高光 | 0x2033 | -9…9 |
| 阴影 | 0x2032 | -9…9 |
| 褪色 | 0x2034 | 0…9 |
| 饱和度 | 0x2005 | -9…9 |
| 锐度 | 0x2006 | 0…9 |
| 锐度范围 | 0x2035 | 1…5 |
| 清晰度 | 0x2036 | 0…9 |

Sony1 和 Sony2 根 MakerNote 按数字标签读取，避免绑定新版本才提供的字段名字。不会把 Minolta/Sony 嵌套 CameraSettings 的另一种量纲直接套上来。新外观专有代码、新八项中的专有有效字段、或已核对的 ILCE-7M4 用作 Creative Look 证据；共享的 Standard/Vivid 名称本身不证明是新 Creative Look。FL 名称加明确 FL2/FL3 ColorMode 可以细化为该子类型；其他矛盾禁用自动应用。相机自定义槽位 1–6 尚无可靠解析，不猜槽位编号；保存了基础外观及微调时照常读取那些字段。

## 技术与性能

元数据只在加载阶段读取，不在每次滑动中解析 RAW。reference/calibration 各使用一执行任务加一个可替换待办；结果绑定照片/参数版本。颜色 LUT 以最多 1089×33 RGBA32F atlas 在 GPU 缓存；只改滑块不重新上传源图。锐度/清晰度启用时才创建两个额外浮点工作纹理，分别水平/垂直处理。预览和导出共享颜色/细节计算；CPU 导出及全分辨率统计以带 halo 的图块计算，避免 128 行边缘接缝。

Fit 预览的细节在缩小图上处理，不能代替原始分辨率细节检查；100% 裁切视区边缘和整图邻域可能有差异，应以全分辨率输出验收。参考直方图仅统计实际参考预览，不标成 RAW 全分辨率统计。输入/输出版本 `jixellight-linear-v3-look1`，旧磁盘预览失效。基础 GPU 验收限值继续为 40/65535，没有降低精度门槛来通过测试。
